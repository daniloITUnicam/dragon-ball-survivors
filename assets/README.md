# assets

- **`menu.mp3`** – main-menu song (also plays on character select).
- **`namek.mp3`** – looping track for **Planet Namek** (stage 2).
- **`logo.webp`** – game logo shown in the main menu. `docs/logo.png` is the same image for the README.

Both songs were generated by the author with **Suno** (AI-generated music) and are included in the repository.
`build.py` embeds them (and the logo) as base64 in the final HTML. If a file is missing the game simply falls back
to the procedural (synthesised) music, so the build never breaks. To use your own tracks, replace the files keeping the same names
(ideally re-encoded to ~96 kbps to keep the build small).

## Layout

- `*.mp3` / `gacha.mp4` – music, sound effects and the gacha video, kept at the root of `assets/` (the link build serves them as `assets/<file>` next to `index.html`).
- `ui/` – HUD / menu art embedded by `build.py`: `logo`, `wip`, `machine` (Swap Machine sheet), `dragonballs`, the bar atlases `hpbar` / `xpbar` / `tgt` (generated by `tools/gen_*.py`), `menu/` (main-menu buttons) and `cardframes/` (rarity frames).
- `icons/` – one `<id>.webp` per item: `shop/`, `weapons/`, `trinkets/`, `abilities/` (characters, fusions, `senzu`, `dash`), `hud/`.
- `sprites/` – the game sprites, see `sprites/README.md` (sources in `sprites/_sorgenti/`, including `hud/mockup.png`).
