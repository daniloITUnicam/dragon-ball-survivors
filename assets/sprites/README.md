# Sprite sheets dei personaggi (opzionale)

Metti qui i PNG dei tuoi sprite e ricompila (`python3 build.py`): sostituiscono la grafica generata dal codice.
Nomi: `<id>.png` (forma base) e `<id>_<n>.png` (trasformazione n, da 0). Guida completa: [`docs/SPRITES.md`](../../docs/SPRITES.md).
Nome sbagliato o file non PNG = ignorato (la build lo segnala).
